# ShareWe Landing

ShareWe 对外展示网站的静态页面源代码。

## 页面

| 文件 | 作用 |
| --- | --- |
| `index.html` | 网站首页 |
| `standard.html` | 服务说明页面 |
| `sample.html`、`sample-anker.html` | 示例展示 |
| `privacy.html` | 隐私相关页面 |
| `deploy.sh` | 部署脚本 |

## 维护规则

- 本仓库为**公开仓库**，不要提交 API Key、服务器登录凭据、客户隐私或其他内部业务数据。
- 部署前应人工检查页面内容、外链、联系方式和隐私说明，并确认当前生产发布环境。
- 修改网页与执行 `deploy.sh` 是两类不同操作；更新本仓库不会自动证明线上网站已经发布。
- Claude 不得连接本 GitHub 仓库，AI 协作应遵守用户授权。

> 此文件仅提供仓库导航，没有改变网站页面或发布流程。
